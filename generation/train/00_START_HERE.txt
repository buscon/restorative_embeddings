🎯 KEY EVALUATION THRESHOLD:

After Step 5, check the pleasantness effect (Spearman correlation):
  
  r > 0.4   → ✓ CLEAR EFFECT, proceed to listening test
  r < 0.3   → ✗ NO EFFECT, try different hyperparameters or more data
  0.3-0.4   → ⚠ MARGINAL, gather listening test feedback

   → Creates HTML form + anonymized clips
   → 20-30 minutes to complete
