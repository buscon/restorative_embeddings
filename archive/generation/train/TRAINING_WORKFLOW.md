# Stable Audio Open Fine-Tuning Workflow

This directory contains scripts for fine-tuning the Stable Audio Open base model on the ARAUS restorative soundscapes dataset (6,000 samples with pleasantness-conditioned captions).

## Prerequisites

- Stable Audio Tools environment installed at `~/stableaudio/venv/`
- ARAUS dataset: audio files at `~/Documents/restorative_embeddings/data/generation/audio/`
- Metadata CSV at `~/Documents/restorative_embeddings/data/generation/export_metadata.csv`
- RTX 5090 GPU (or adjust batch_size/grad_accum_steps for your GPU)

## Training Pipeline

### Step 1: Setup Environment (Optional - verify setup)
```bash
python 01_setup_environment.py --stableaudio-path ~/stableaudio
```
This verifies your virtual environment and stable-audio-tools installation.

### Step 2: Generate Training Configuration
```bash
python 02_prepare_training_config.py --model-size base --batch-size 1 --num-epochs 3
```
This generates `config_sao_base.yaml` with:
- Model: stabilityai/stable-audio-open-1.0 (1.1B parameters, 30-second audio)
- Dataset: 6,000 ARAUS samples at 44.1 kHz, 16-bit, -23 LUFS
- Batch size: 1 (with 8x gradient accumulation = effective batch size 8)
- Learning rate: 5.0e-5
- Estimated time: ~420 hours on RTX 5090 (3 epochs)

**Output:** `config_sao_base.yaml`

### Step 3: Run Training
```bash
python 03_run_training.py --config config_sao_base.yaml
```

This executes:
```bash
python -m train --config config_sao_base.yaml
```

The built-in `python -m train` command from stable-audio-tools handles:
- Data loading from CSV with pleasantness-conditioned text
- Mixed-precision training (fp16)
- Checkpoint saving every 500 steps
- Logging and metrics tracking

**Resume from checkpoint:**
```bash
python 03_run_training.py --config config_sao_base.yaml --resume-from checkpoints/checkpoint_step_500.pt
```

## CSV Metadata Format

Expected columns in `export_metadata.csv`:
- `export_id`: Unique ID
- `stimulus_id`: Stimulus identifier
- `caption`: Text conditioning (e.g., "pleasant bird sounds in forest")
- `ISOPleasant`: ISO pleasantness rating (0-100)
- `bin`: Pleasantness bin (very_unpleasant, unpleasant, neutral, pleasant, very_pleasant)
- `LA50`: Sound level
- `wav_path`: Path to audio file (relative or absolute)

Example row:
```
export_id,stimulus_id,caption,ISOPleasant,bin,LA50,wav_path
1,S001,pleasant birds chirping in a quiet forest,78,pleasant,45.2,audio/stim_001.wav
```

## Model Configuration

### Base Model (Default)
- **Name:** stabilityai/stable-audio-open-1.0
- **Parameters:** 1.1B
- **Audio duration:** 30 seconds
- **Sample rate:** 44.1 kHz
- **Time per step:** ~35 seconds (RTX 5090)
- **Total training time:** ~420 hours (3 epochs)

### Small Model (Alternative)
```bash
python 02_prepare_training_config.py --model-size small
python 03_run_training.py --config config_sao_small.yaml
```

- **Name:** stabilityai/stable-audio-open-1.0-small
- **Parameters:** 341M
- **Audio duration:** 11 seconds
- **Sample rate:** 44.1 kHz
- **Time per step:** ~12 seconds (RTX 5090)

## Training Parameters

Edit these arguments when running step 2:

```bash
python 02_prepare_training_config.py \
  --model-size base \
  --batch-size 1 \
  --grad-accum-steps 8 \
  --num-epochs 3 \
  --learning-rate 5.0e-5 \
  --warmup-steps 500
```

## Troubleshooting

**ModuleNotFoundError: No module named 'stable_audio_tools'**
```bash
source ~/stableaudio/venv/bin/activate
pip install stable-audio-tools
```

**CUDA out of memory**
- Reduce batch_size to 1 (already set)
- Reduce gradient_accumulation_steps
- Reduce audio duration in config

**Audio files not found**
- Verify CSV `wav_path` column is correct
- Check that audio files exist at specified paths
- Paths can be relative (to audio_dir) or absolute

## Generated Configuration Format

The `config_sao_base.yaml` generated by step 2 follows the official stable-audio-tools format:

```yaml
data:
  train_path: /path/to/export_metadata.csv
  audio_dir: /path/to/audio
  sample_rate: 44100
  duration: 30.0
  channels: 2
  text_key: caption
  file_key: wav_path

model:
  pretrained_model_name_or_path: stabilityai/stable-audio-open-1.0

train:
  output_dir: /path/to/checkpoints
  num_train_epochs: 3
  per_device_train_batch_size: 1
  gradient_accumulation_steps: 8
  learning_rate: 5.0e-5
  warmup_steps: 500
  weight_decay: 0.01
  max_grad_norm: 1.0
  mixed_precision: fp16
  optimizer: adamw_torch
  scheduler: cosine
  max_steps: 2000
  save_interval: 500
  logging_steps: 50
```

## Notes

- Training uses **mixed-precision (fp16)** for faster convergence and lower memory usage
- Gradient accumulation with batch_size=1 and grad_accum_steps=8 gives effective batch size of 8
- Checkpoints are saved every 500 steps (~4.8 hours on RTX 5090)
- Learning rate uses **cosine annealing** scheduler with warmup
- Text conditioning uses the `caption` column from your metadata CSV
